## Wortarten-Endungen

| Endung | Wortart |
|---|---|
| -a | Nomen |
| -e | Adjektiv |
| -i | Verb (Grundform) |
| -o | Adverb |

Jede Wurzel unten kann mit jeder Endung kombiniert werden (kal → kala/kale/kali/kalo).

## Grammatische Partikel

**Rollen (Vokal a):**

| Partikel | Rolle |
|---|---|
| (kein Marker) | Subjekt/Thema |
| li | leitet das Prädikat ein (Präsens) |
| e | direktes Objekt |
| ta | Ort |
| ma | Zeit |
| ka | Empfänger (indirektes Objekt) |
| fa | Mittel/Werkzeug |

**TAM/Satztyp (Vokal e):**

| Partikel | Funktion |
|---|---|
| pe | Vergangenheit |
| ke | Zukunft |
| we | Imperativ |
| me | Frage (satzfinal) |
| te | Plural (vor dem Nomen) |
| no | Verneinung (vor dem Verb, nach li/pe/ke/we) |

**Logik (Vokal o):**

| Partikel | Bedeutung |
|---|---|
| ko | und |
| wo | oder |
| no | nicht |
| so | wenn ..., dann ... |
| po | um ... zu (Zweck) |
| pi ... na | Klammer (nur schriftlich) |

**Antwort (ja/nein):**

| Klar | Bedeutung |
|---|---|
| pa | ja |
| no | nein (= dieselbe Verneinung) |

**Weitere Konstruktionen (ohne eigene Partikel):**

| Muster | Bedeutung |
|---|---|
| Pronomen + -e | Possessiv (mi→mie „mein", si→sie „dein", nu→nue „sein/ihr") |
| pulo ADJEKTIV komo X | Komparativ („größer als": pulo kale komo X) |
| Adjektiv ohne li | Kopula-lose Prädikation („ist groß": kale) |
| V1 (+Objekt) V2 | Serialverb, informell, enges Ereignis (teki e X lemi = „X mitnehmen") |

## Kernwortschatz (Wurzeln)

**Personen/Familie:** mam = Mutter · nan = Vater · tun = Kind

**Natur:** wer = Wasser · pir = Feuer · sat = Ort/Bahnhof-artiger Ort · lun = Mond

**Handlungen:** man = essen · lem = gehen · pak = brechen · lor = ruhen/schlafen · fid = sehen · dik = sagen · ben = kommen · don = geben · res = bleiben · bol = wollen · sal = grüßen · gan = danken · fen = fühlen · tek = nehmen

**Eigenschaften:** kal = groß · pik = klein/spitz · mol = weich/rund · rop = schnell · mil = freundlich · gel = froh/glücklich · war = warm

**Sonstiges:** dom = Haus · pul = mehr · kom = Vergleich · nun = jetzt/heute · wud = wünschen · din = Tag · poi = später/danach

**Ziffern 0–9:** nul · un · dua · fin · fer · pen · sik · sep · ok · nom

*Kanalrobustheit: Kein Wortpaar unterscheidet sich nur durch Stimmhaftigkeit (p/b, t/d, k/g) oder nur durch r/l — Ersetzung r→l ist bei eingeschränkter Aussprache gefahrlos möglich (Details: Entwurfsdokument 7.1).*
