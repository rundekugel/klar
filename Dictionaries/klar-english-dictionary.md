## How to read this list

Every entry is a bare **root**. Add a class ending (Entwurfsdokument 4.1) to get a real word:

| Ending | Word class | Example |
|---|---|---|
| -a | noun | kop**a** = "the head" |
| -e | adjective | kop**e** = "head-like" |
| -i | verb | kop**i** = "to head/lead" |
| -o | adverb | kop**o** = "in a head-way" |

Not every root is equally natural in every class (e.g. `kop` is mainly used as a noun) — but the rule always applies, no exceptions (Prinzip 1).

## Notes

- All 94 roots were checked against the full existing lexicon and grammatical particles (Entwurfsdokument, ~60 items) plus each other — zero collisions, zero voicing-only minimal pairs, zero r/l minimal pairs, all phonotactically legal (K)V structure.
- A few roots lean on English/international mnemonics where it didn't cost anything (`new`=neu, `gud`=gut, `bad`=schlecht, `sit`=sitzen, `dog`=Hund, `kat`=Katze) — purely a memorization aid, not a grammatical rule.
- This is tranche 1 (~94 words). Target from the Entwurfsdokument (Prinzip 4) is 300–500 roots — further tranches can follow the same validated process.
